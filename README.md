# 中国奶蛙科技大学

一个独立的个人创意校园官网导航页，按用户提供的名单收录 43 所学校。名称采用用户修改后的“中国奶蛙科技大学”。

## 使用

打开 `dist/index.html`，选择学校并点击“出发，访问官网”。网站会在新标签页打开对应的官方网站。待添加位置不可跳转。

也可以点击“逛一逛”，从全部 43 个已加入的有效官网网址中等概率随机选择并立即在新标签页打开。重复网址只参与一次抽样，待添加位置不参与；连续点击允许重复抽中。今后在学校列表中新增网址后，会自动加入随机范围。

搜索框支持按学校名称或域名查找；“逛一逛”始终使用完整名单，不受搜索结果影响。随机选中后会清空搜索并更新当前学校。页面默认选中湖南科技大学。

点击“出发，访问官网”或“逛一逛”后，网站会先在页面中播放一段 `transit.mp4` 出发动画（开头第 1 秒片头已裁掉），同时在后台预检目标官网；检测到目标加载完成后动画自动关闭，并在新标签页打开官网。目标加载越快动画越短（最短约 1.2 秒，最长到视频结束约 14 秒）。如果新标签页被浏览器拦截，页面会显示“若官网没有打开，请点击：…官网 ↗”的手动链接。如果浏览器不支持该视频格式或用户开启了减少动画，会自动改用吉祥物动画；动画期间可随时点击“跳过动画”立即前往。

## 添加学校

编辑 `dist/schools.js`，在列表中添加对象，填写唯一 `id`、学校名称 `name`、辅助文字 `location`（域名或地区）和 HTTPS 官网地址 `url`。可选的 `note` 会优先作为卡片辅助文字显示。页面会自动生成学校选项和数量。示例结构如下（请替换为真实信息）：

```js
{
  id: "another-school",
  name: "学校名称",
  location: "省份 · 城市",
  url: "https://学校官网域名/"
}
```

修改后需重新发布，线上页面才会更新。网站是纯静态页面，不需要账号、数据库或构建步骤；支持电脑、手机、键盘操作和减少动画设置。

## 文件

- `dist/index.html`：页面内容
- `dist/styles.css`：配色、布局和移动端样式
- `dist/schools.js`：学校列表
- `dist/app.js`：选择、随机探索和跳转
- `dist/transit.mp4`：出发动画视频（H.264 + AAC，竖屏 9:16）
- `dist/mascot.jpg`：用户提供的吉祥物原图
- `dist/favicon.svg`：浏览器图标

部署到其他静态托管服务时，将 `dist` 文件夹内容作为网站根目录上传即可。
