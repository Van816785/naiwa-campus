# 中华奶龙科技大学

一个独立的个人创意校园官网导航页，已接入湖南科技大学官网。

## 使用

打开 `dist/index.html`，选择学校并点击“出发，访问官网”。网站会在新标签页打开对应的官方网站。待添加位置不可跳转。

## 添加学校

编辑 `dist/schools.js`，在列表中添加对象，填写唯一 `id`、学校名称 `name`、地区 `location` 和已确认的 HTTPS 官网地址 `url`。页面会自动生成学校选项和数量。示例结构如下（请替换为真实信息）：

```js
{
  id: "another-school",
  name: "学校名称",
  location: "省份 · 城市",
  url: "https://学校官网域名/"
}
```

修改后需重新发布，线上页面才会更新。网站是纯静态页面，不需要账号、数据库或构建步骤；支持电脑、手机、键盘操作和减少动画设置。

## 文件

- `dist/index.html`：页面内容
- `dist/styles.css`：配色、布局和移动端样式
- `dist/schools.js`：学校列表
- `dist/app.js`：选择和跳转
- `dist/mascot.svg`：原创小龙插画
- `dist/favicon.svg`：浏览器图标

部署到其他静态托管服务时，将 `dist` 文件夹内容作为网站根目录上传即可。
