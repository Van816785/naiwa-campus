# 中国奶蛙科技大学

一个独立的个人创意校园官网导航页，目前已收录 43 所学校。名称为“中国奶蛙科技大学”。

## 使用

打开 `dist/index.html`，选择学校并点击“出发，访问官网”，或点击“逛一逛”。本次点击会立即在新页面打开学校官网，同时在本站内嵌播放约 14 秒的 `transit.mp4`，官网加载不等待视频结束。

- 点击“结束视频，查看官网”：结束本站视频，尝试切换到已经打开的官网，不重新加载它。
- 点击“继续看完”：继续播放本站视频。自然播放结束后，也只尝试切换到已有官网页面。
- 浏览器可能直接切换到新页面；可以返回本站继续观看。网站无法强制所有浏览器将官网放到后台，也无法可靠读取跨域官网是否已经完全加载，所以不会显示虚假的“加载完成”提示。
- 新页面被拦截时会明确提示，提供“结束视频，打开官网”和“在当前页打开官网”普通链接，可立即访问。
- 视频失败不会阻止已经打开的官网。开启“减少动态效果”时直接打开官网，不播放视频。可以用视频控件暂停和继续；没有强制观看倒计时。

“逛一逛”始终从全部 43 个有效且不重复的网址中等概率随机选择，不受搜索影响。转场期间重复点击不会另开多个目的地；以后在列表新增有效网址，会自动加入随机范围。

微信和其他手机浏览器可能限制新页面或暂停后台视频，网站无法强制两个页面同时保持前台播放。测试覆盖桌面引擎及手机模拟，不代表微信真机认证。测试详情见 `兼容性测试报告.md`。

## 添加学校

编辑 `dist/schools.js`，在列表中添加对象，填写唯一 `id`、学校名称 `name`、辅助文字 `location`（域名或地区）和 HTTPS 官网地址 `url`。可选的 `note` 会优先作为卡片辅助文字显示。页面会自动生成学校选项和数量。示例结构如下（请替换为真实信息）：

```js
{
  id: "another-school",
  name: "学校名称",
  location: "省份 · 城市",
  url: "https://学校官网域名/"
}
```

修改后需重新发布，线上页面才会更新。网站是纯静态页面，不需要账号、数据库或构建步骤；支持电脑、手机、键盘操作和减少动画设置。

## 文件

- `dist/index.html`：页面内容
- `dist/styles.css`：配色、布局和移动端样式
- `dist/schools.js`：学校列表
- `dist/app.js`：选择、随机探索和跳转
- `dist/transit.mp4`：出发动画视频（H.264 + AAC，竖屏 9:16）
- `dist/mascot.jpg`：用户提供的吉祥物原图
- `dist/favicon.svg`：浏览器图标

部署到其他静态托管服务时，将 `dist` 文件夹内容作为网站根目录上传即可。
