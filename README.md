# 中国奶蛙科技大学

一个独立的个人创意校园官网导航页，目前已收录 43 所学校。名称为“中国奶蛙科技大学”。

## 使用

打开 `dist/index.html`，选择学校并点击“出发，访问官网”，或点击“逛一逛”。页面停留在本站，播放 `transit.mp4`，同时通过不可见、受沙箱限制的 iframe 尝试后台加载选定官网。不会打开新标签页。

- 视频真实触发 `ended` 后，当前页自动导航到学校官网。
- “跳过视频，立即进入”是当前页普通链接，可随时提前访问。
- “继续看完”恢复暂停的视频；用户暂停时不会按固定倒计时跳转。
- 视频不可播放或持续缓冲时，提示后自动前往官网，避免卡死。
- 官网可能禁止嵌入；跨域 iframe 的 load 事件无法证明成功加载，因此不会显示虚假完成状态。正式跳转可能重新请求资源，不能保证瞬间显示已加载的网页。
- 不绕过学校的嵌入限制，不等待后台 iframe 成功才允许进入官网。

“逛一逛”从全部 43 所学校等概率选择，不受搜索过滤影响。微信真机和 Safari 应用尚未实测。

## 添加学校

编辑 `dist/schools.js`，在列表中添加对象，填写唯一 `id`、学校名称 `name`、辅助文字 `location`（域名或地区）和 HTTPS 官网地址 `url`。可选的 `note` 会优先作为卡片辅助文字显示。页面会自动生成学校选项和数量。示例结构如下（请替换为真实信息）：

```js
{
  id: "another-school",
  name: "学校名称",
  location: "省份 · 城市",
  url: "https://学校官网域名/"
}
```

修改后需重新发布，线上页面才会更新。网站是纯静态页面，不需要账号、数据库或构建步骤；支持电脑、手机、键盘操作和减少动画设置。

## 文件

- `dist/index.html`：页面内容
- `dist/styles.css`：配色、布局和移动端样式
- `dist/schools.js`：学校列表
- `dist/app.js`：选择、随机探索和跳转
- `dist/transit.mp4`：出发动画视频（H.264 + AAC，竖屏 9:16）
- `dist/mascot.jpg`：用户提供的吉祥物原图
- `dist/favicon.svg`：浏览器图标

部署到其他静态托管服务时，将 `dist` 文件夹内容作为网站根目录上传即可。
